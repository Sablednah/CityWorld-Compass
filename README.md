# CityWorld Compass

Nature's Compass for [CityWorld](https://www.curseforge.com/minecraft/mc-mods/cityworld-reforged)'s cities. Right-click
the **Urban Compass**, pick what you are looking for — a hospital, a shopping mall, a subway station, a bookshop, the
industrial district, a named building like the Winchester — and the needle points to the nearest one.

- **Every place CityWorld builds is on the list**, grouped as the nearest city, places, shops by trade, districts and
  named buildings, with a search box.
- **Nothing is generated to find it.** The compass asks CityWorld's city plan, so it finds places in land nobody has
  visited yet, and the search runs off the server thread.
- **Sneak-use searches again** for the same place from where you now stand.
- **Get one** by crafting (a compass ringed with bricks, lodestones in the corners) or, very rarely, from a CityWorld
  chest.

Needs CityWorld 6.6.0 or later. Six Minecraft lines: 1.20.1 (Forge), 1.21.1, 1.21.11, 26.1, 26.2 and 26.3 (NeoForge).

GPL-3.0-only, like CityWorld, whose API it builds on.
